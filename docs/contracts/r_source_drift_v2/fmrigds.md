# R-source drift v2: fmrigds 0.1.0.9002 (`67cc585`..`cb5f44b`)

Part of [`r_source_drift_inventory_v2.md`](../r_source_drift_inventory_v2.md). The classes, method and wave plan are defined there. `repro/` scripts run against fmrimod HEAD `4f14a19` with `.venv/bin/python`.

Range: 32 non-merge commits, 68 R/src files changed. Refactor-only work: CRAN readiness and housekeeping (`dacf059`, `03c8b63`, `f936ee1`, `3ae10e8`, `95e85f4`, `1c8639a`, `9fc569c`, `60e9242`, `829139e` coverage workflow and badges); `311f312` touches only roxygen (every changed R line is `#'`); `98bcf2b` trims the exported API and adds a `contrasts()` default method; `10d28f8` imports Rcpp and moves fmridataset/multidesign to Suggests; `216c837` OpenMP thread fallback; `4150544` replaces `$` with `[[` to avoid R partial matching; `5ed851b` fits complete samples of `ols:voxelwise` in one matrix step ("Results are unchanged"); plus the R-engine parts of `e359af6` (save/load_plan, preview/compute(block), plan `subjects()`/`contrasts()`, deleted dead optimizer and legacy `.reduce_effects`/`.reduce_evidence` paths, `fdr:spatial` rewritten with `split()`) and of `8b145f9` (catalog, CLI, fmristore, neuroim exporters, the R-side HDF5 affine read, the `voxel/storage` dataset, empty provenance logs). Migration: four new fmrigds features came over from fmrireg so that fmrireg can delegate its group layer to fmrigds. `fdr:sabha`/`spatial_fdr_sabha()` is `fmrireg::spatial_fdr()` (fmrireg `3ea2a2b` now delegates to it). `ttest:welch` and `coef_contrast()` back fmrireg's `fmri_ttest` OLS/Welch engines and its classic contrasts (fmrireg `3ed5e8d`, `0038b31`). NIfTI t/df input backs fmrireg's `group_data` t maps (fmrireg `e2b79f8`). `fmri_meta()` on gds data also reduces through fmrigds (fmrireg `cfb4389`).
